🌦️ Global Weather App
A responsive web application that allows users to get real-time weather updates for any city around the world. Built with modern web technologies and integrated with live weather APIs, this app delivers essential weather information in a clean and intuitive interface.

🔍 Overview
The Global Weather App fetches and displays live weather data including temperature, humidity, wind speed, and weather conditions for any location entered by the user. It enhances the user experience by providing a visually appealing and interactive design, making weather tracking simple and efficient.

Key features include:
Real-time weather updates via API integration
Search functionality for global cities
User-friendly and responsive UI
Dynamic display of weather icons and conditions

💻 Technologies Used
HTML/CSS/JavaScript – Frontend development
React.js (if applicable) or Vanilla JavaScript – Interactive UI handling
OpenWeatherMap API – For retrieving live weather data
Bootstrap / TailwindCSS – For responsive and styled layout

🎨 Features
Live Search: Enter any city to fetch current weather data instantly
Weather Display: Temperature, condition, humidity, and wind info
Responsive Design: Optimized for desktop and mobile devices
Dynamic Icons: Visual cues for different weather conditions

🔑 API Setup
Sign up at OpenWeatherMap
Get your free API key
Replace the placeholder API key in the code with your own to start fetching data
